# Correctness audit — 2026-07-07

A 12-subsystem adversarial audit (80 agents: per-subsystem finders, then an
independent refuter **and** reproducer per finding — a finding counted only if
both upheld it). Result: 34 raw findings → **33 confirmed**, 1 rejected, 0
contested. **25 were fixed same-day** with regression tests (test count
193 → 278); 8 are deferred with rationale below. Severities are the audit's.

## Process notes

- Every fix has a colocated regression test where the layer is testable
  (data/geometry/engine/store); UI-widget fixes (NumberField, ExprField,
  OperationConfirm binding, NodeView normals) follow this repo's convention of
  manual verification.
- Same-day hardening (separate from the audit): property-based suites for the
  solver, the structural-hash mutation coverage (every geometry-affecting
  field must bust the cache), and full-document serialization round-trips.
